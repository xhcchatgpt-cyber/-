# Self-OS 知识库

本仓库记录了 Self-OS 的核心组成与职责，便于在 Notion、API 或 AI 工作流中快速查阅和协作。

## 自我介绍
Self-OS 旨在把琛哥的商业方法论产品化，将策略落地为可执行的智能代理集群。
- 价值主张：用清晰的规则与 SOP 驱动，让每个 Agent 都能复用“主法典”并稳定输出。
- 工作方式：依托 Notion / API / AI 工作流，将采集、分析、创作、跟进的动作自动化串联。
- 预期收益：在诊断、获客、转化、裂变的完整链路上，降低试错成本、提升响应速度。

## 体系结构
```
Self-OS
├─ 琛哥商业 Codex（主法典）：沉淀商业方法论与可复用的决策准则。
│
├─ GEO 搜索体检 Agent（诊断）：面向市场/竞品的搜索、体检与现状诊断。
├─ 内容引流 Agent（流量）：生产并分发内容，提升外部流量与曝光。
├─ 私域转化 Agent（成交）：运营私域用户，完成跟进、培育与转化。
├─ 合作人管理 Agent（裂变）：管理合伙/合作人关系，支持裂变式增长。
│
└─ 工具调度层（Notion / API / AI 工作流）：统一的工具编排与数据同步层。
```

## 使用建议
- 以主法典为“北极星”，在任何 Agent 上线或迭代前先对齐原则。
- 每个 Agent 的输出应回写到 Notion 或自动化工作流中，形成闭环。
- 建议为各 Agent 单独建立 SOP、Prompt 模板与指标看板，便于复用和评估。
